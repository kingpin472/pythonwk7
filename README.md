
📊 Iris Dataset Analysis Project
This project performs exploratory data analysis (EDA) and data visualization on the classic Iris dataset, using pandas, matplotlib, and seaborn. It also includes basic data cleaning and group-wise analysis.

✅ Features
Load Iris dataset from sklearn

Simulate and handle missing values

Compute summary statistics

Group by species and analyze averages

Generate 4 types of visualizations:

Line chart

Bar chart

Histogram

Scatter plot
